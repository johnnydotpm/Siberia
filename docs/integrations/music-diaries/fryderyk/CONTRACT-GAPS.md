All route names below are observed literals, **not executable specifications**. Locate their original-app callers before constructing requests. Priority P0 blocks authentication and all data access; P1 blocks core diary support; P2 blocks full feature parity. Static evidence references are in `curated-evidence.json` and `feature-evidence.json`.

For each completed probe retain: exact app version and original hash, role, original caller/source offset, route construction, HTTP method, redacted request/response fixture, nullability, enum/error cases, observed side effects and confidence. Separate inferred behavior from executed observations. Review artifacts before publication: remove tokens, QR secrets, personal school/student data and embedded service credentials. Keep app binaries/raw AOT dumps local.

The existing iOS scanner is locked to SHA-256 `2c11d5a1be3f1f21d85c2b9c4deb8c59d2c3c33dfd9eebf0235657bcc6f7cca1`; hardcoded snapshot range/class IDs are only a build-specific literal recovery method. Android scan is ASCII-only and does not fully recover UTF-16/non-ASCII localization. Native Dart-aware call-site recovery is still required for static proof of contracts.
