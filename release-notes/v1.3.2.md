## What's new
- The Android APKs are signed with the project's key again. Updates from now on install over this version.
- Patch updates of notifications, link opening and settings storage (`flutter_local_notifications` 22.3.2, `url_launcher` 6.3.3, `shared_preferences` 2.5.6).
- The automated tests are back and run on every change.

## Updating from v1.3.1 on Android
The v1.3.1 APKs were signed with a temporary key, because the new repository had no signing key yet. Android won't install v1.3.2 over them. Uninstall v1.3.1 first, then install v1.3.2 and sign in to Librus again. v1.3.0 and earlier have the same key as v1.3.2 and update directly.
