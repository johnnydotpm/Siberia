# SiberiaGB

[Polski](README.md) | [English](README.en.md) | **Русский**

SiberiaGB представляет собой полнофункциональный кроссплатформенный клиент Librus, написанный с использованием фреймворка [Flutter](https://flutter.dev/).

## Возможности

- Вход с неистекающими сессиями
- Расписание уроков в виде шкалы времени или списка, со сдвоенными уроками одной карточкой и контрольными у тех уроков, на которые они назначены
- Оценки в цветах по значению и расчёт среднего балла, в том числе средневзвешенного, со своей ценой плюсов и минусов
- Калькулятор оценок: как изменится средний балл с новыми оценками и сколько оценок нужно до желаемого
- Планировщик, календарь и предстоящие события
- Домашние задания по срокам сдачи, с поиском
- Экран «Сегодня» с текущим и следующим уроком и блоками, которые можно скрывать и переставлять
- Виджет «Следующий урок» на главном экране (Android и iOS), с отдельными настройками для каждого виджета на Android
- Полная поддержка сообщений
- Объявления
- Посещаемость с диаграммой присутствия
- Замечания
- Уведомления по восьми категориям: оценки, сообщения, объявления, замечания, посещаемость, события, домашние задания и расписание
- Напоминания о контрольных накануне вечером или утром в тот же день, в выбранное время (Android и iOS)
- Фоновая синхронизация данных (Android)
- Приложение доступно на пяти языках: польском, английском, русском, немецком и украинском
- Работает на Android, iOS, Windows и Linux
- Дизайн Liquid Glass: на iOS 26 и новее на настоящих системных панелях, на Android 10 и новее воссоздан самим приложением в тех же размерах; классический дизайн остаётся доступным в настройках

## Установка

Скачайте файл для нужной платформы, затем запустите его или установите приложение.

На Android файл `SiberiaGB-<версия>-Android-arm64.apk` меньше и подходит почти любому телефону последних лет. Если он не устанавливается, скачайте `SiberiaGB-<версия>-Android.apk`, который работает на любом телефоне с Android, включая старые 32-битные. Любой из этих файлов обновляет приложение, установленное из другого.

На iOS приложение необходимо установить самостоятельно с помощью [AltStore](https://altstore.io/), [SideStore](https://sidestore.io/), [LiveContainer](https://github.com/LiveContainer/LiveContainer) или платного сертификата.

Виджет «Следующий урок» на главном экране работает при установке через AltStore, SideStore или платный сертификат; LiveContainer виджеты не поддерживает. На бесплатном Apple ID виджет занимает один дополнительный App ID.

Для тестирования интерфейса без школьного аккаунта удерживайте логотип на экране входа пять секунд. Демонстрационный режим содержит вымышленные оценки, сообщения, замечания, посещаемость, уроки и события календаря. Сообщения и обновление работают локально; выйдите из аккаунта, чтобы завершить демо. Демонстрационные данные не сохраняются между запусками приложения.

## Инструкции по сборке

Для любой локальной сборки нужен [Flutter SDK](https://docs.flutter.dev/get-started/install). Сначала выполните в корневом каталоге проекта:

```sh
cd syberia
flutter pub get
```

<details>
<summary>Android</summary>

Требуются Android SDK и настроенное окружение Flutter.

```sh
flutter build apk --release
```

APK будет находиться в `build/app/outputs/flutter-apk/app-release.apk`.

Без локального Android SDK: запустите workflow `SiberiaGB Flutter` в GitHub Actions с включённой опцией `build_android`, затем скачайте артефакт `siberiagb-android`.

Сборка со своего компьютера подписана отладочным ключом, поэтому не установится поверх опубликованного релиза. В GitHub Actions APK подписывается ключом проекта из секретов репозитория `ANDROID_KEYSTORE_BASE64` и `ANDROID_KEYSTORE_PASSWORD`; без них тоже отладочным. Сборка с отладочным ключом ставится отдельным приложением SiberiaGB Preview рядом с опубликованным, а релиз без ключа сделать нельзя.

</details>

<details>
<summary>iOS</summary>

Для локальной сборки нужны macOS, Xcode и Apple Developer Team, настроенная в проекте Xcode.

```sh
flutter build ipa --release
```

GitHub Actions не требует Mac: запустите workflow `SiberiaGB Flutter` с включённой опцией `build_ios`, затем скачайте артефакт `siberiagb-ios`. Подпишите и установите IPA самостоятельно, например через AltStore или SideStore.

</details>

<details>
<summary>Windows</summary>

Требуются Windows и Visual Studio с компонентом **Desktop development with C++**.

```powershell
flutter build windows --release
```

Приложение будет находиться в `build/windows/x64/runner/Release`.

</details>

<details>
<summary>Linux</summary>

Требуется Linux с установленными desktop-зависимостями Flutter.

```sh
flutter build linux --release
```

Приложение будет находиться в `build/linux/x64/release/bundle`.

</details>
